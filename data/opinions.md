# Opinions, Values, Hobbies and Society Work - Anas

## Core values
- Correctness first. A result is only good if it solves the actual problem asked.
- Functionality over decoration. I reject unnecessary features, repetitive interfaces and superficial testing.
- Simplicity for users. I am comfortable with complex internals when justified, but the user-facing experience should be simple.
- Efficiency. I watch API calls, cost, hardware limits and architecture size.
- Instruction fidelity. If I ask for a structural redesign, a colour change is not enough. If I ask for one exact edit, nothing else should change.

## Technical opinions
- A page that loads is not a tested feature. Real testing means adding records, changing data, trying edge cases and verifying outcomes.
- Robustness and generalization matter more than a high accuracy number on a clean test set.
- Research must be novel and defensible, so I ask for a hard audit of ideas before investing time.
- Local models and quantization are practical for my hardware, so I avoid recommending huge cloud models without checking resources first.
